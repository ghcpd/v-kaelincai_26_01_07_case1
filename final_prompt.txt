**Bug Description:**
- The `DataNormalizer` class exhibits flaky behavior: identical inputs produce varying outputs
- Tests randomly pass or fail due to non-deterministic behavior
- Scores vary between runs (e.g., 6.87, 7.15, 7.23 for the same data)
- Root cause: Python's unordered `set` data structure for dimension names causes non-deterministic iteration order
- This affects floating-point calculation sequences and threshold-based logic decisions
