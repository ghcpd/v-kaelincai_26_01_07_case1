## Role & Objective

You are a senior software engineer responsible for analyzing, fixing, and validating a flaky behavior bug in a scientific data analysis platform. Your complete objective is to:

1. **Analyze and fix** the non-deterministic bug in the DataNormalizer implementation
2. **Create a complete fixed project** with all corrected source code, tests, and documentation
3. **Execute comprehensive validation** to confirm all tests pass consistently
4. **Verify deterministic behavior** across multiple runs and test scenarios
5. **Document all changes** and summarize validation results

## Inputs & Context

**Source Material:**
- Original buggy project: `issue_project/` directory containing:
  - `src/normalizer.py` (contains non-deterministic bug)
  - `tests/test_normalizer.py` (flaky tests)
  - `data/` folder with sample JSON/CSV files
  - Supporting files: `requirements.txt`, `example_usage.py`, `README.md`, `KNOWN_ISSUE.md`

**Bug Description:**
- The `DataNormalizer` class exhibits flaky behavior where identical inputs produce varying outputs
- Tests randomly pass or fail
- Scores vary between runs (e.g., 6.87, 7.15, 7.23 for the same input data)
- Root cause: Python's unordered `set` data structure for dimension names causes non-deterministic iteration order
- This affects floating-point calculation sequences and threshold-based logic decisions

**Workspace Path:** Create the complete fixed project under workspace directory structure with `issue_project_fixed/` subdirectory

## Step-by-Step Instructions

### Phase 1: Project Analysis & Preparation
1. Examine the original `issue_project/` structure and file organization
2. Read `KNOWN_ISSUE.md` for detailed bug analysis

### Phase 2: Create Fixed Project Structure
1. Create complete directory structure: `<workspace>/issue_project_fixed/`

   - `tests/` (with `__init__.py`)

3. Copy all data files from `issue_project/data/` to `issue_project_fixed/data/`
4. Copy `requirements.txt` from original to fixed project
5. Copy `example_usage.py` from original to fixed project

### Phase 3: Implement the Deterministic Fix
1. **Fix `src/normalizer.py`:**
   - Replace nondeterministic `set` iteration with deterministic ordered iteration (e.g., `sorted(list(data.columns))`)
   - Implement stable summation for weighted accumulation to ensure consistent floating-point calculations
   - Eliminate any order-dependent threshold logic or floating-point operations
   - Maintain all original business logic: Z-score normalization, correlation calculation, weighting strategy

2. **Verify API Preservation:**
   - Ensure the public API remains identical to the original
   - All method signatures, parameters, and return types unchanged
   - Algorithm produces identical results for identical inputs

3. **Update Tests in `tests/test_normalizer.py`:**
   - Update test assertions to expect deterministic behavior
   - Add specific expected values that should be identical across runs
   - Remove any assertions that relied on flaky behavior
   - Ensure tests verify deterministic outcome consistency

4. **Create Test Infrastructure (if needed):**
   - Add `tests/conftest.py` if required for test configuration
   - Ensure proper import paths and test discovery

### Phase 4: Copy Documentation
