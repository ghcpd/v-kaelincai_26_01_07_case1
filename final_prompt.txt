## Inputs & Context

**Source Material:**
- Original buggy project directory: `issue_project/` containing:
  - `src/normalizer.py` (contains non-deterministic behavior bug)
  - `tests/test_normalizer.py` (flaky tests)
  - `data/` folder with sample JSON/CSV files
  - Supporting files: `requirements.txt`, `example_usage.py`, `README.md`, `KNOWN_ISSUE.md`

**Bug Characteristics:**
- `DataNormalizer` class produces non-deterministic outputs for identical inputs
- Tests randomly pass or fail
- Scores vary between runs (e.g., 6.87, 7.15, 7.23 for the same data)
- Root cause: Unordered Python `set` data structure for storing dimension names causes non-deterministic iteration order
- This affects floating-point calculation sequences and threshold-based logic decisions

**Working Directory:** Create project structure under workspace directory `oswe-mini-prime-new`
