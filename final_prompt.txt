## Role & Objective

You are a senior software engineer specializing in fixing flaky behavior bugs in scientific data analysis platforms. Your task is to:

1. **Analyze and fix** a non-deterministic bug in a data normalization system
2. **Create a complete fixed version** of the project that passes all tests consistently
3. **Validate and document** all changes with comprehensive testing and verification

## Inputs & Context

**Source Material:**
- Original buggy project directory: `issue_project/` containing:
  - `src/normalizer.py` (buggy implementation)
  - `tests/test_normalizer.py` (flaky tests)
  - `data/` folder with sample JSON/CSV files
  - `requirements.txt`, `example_usage.py`, `README.md`, `KNOWN_ISSUE.md`

**Bug Characteristics:**
- The `DataNormalizer` class produces non-deterministic outputs for identical inputs
- Tests randomly pass or fail due to non-deterministic behavior
- Scores vary between runs (e.g., 6.87, 7.15, 7.23 for the same data)
- Root cause: Use of unordered Python `set` data structure for storing dimension names, causing non-deterministic iteration order

## Step-by-Step Instructions

### Phase 1: Preparation & Analysis
1. Read and analyze the FIX_PROMPT.md document for complete context about the bug and requirements
2. Examine the original project structure in `issue_project/`
3. Study the buggy implementation in `src/normalizer.py`
4. Review `KNOWN_ISSUE.md` for detailed bug analysis
5. Understand the flaky tests in `tests/test_normalizer.py`

### Phase 2: Create Fixed Project Structure
1. Create a new directory named `issue_project_fixed/` in the workspace
2. Create the following subdirectories:
   - `issue_project_fixed/src/`
   - `issue_project_fixed/tests/`
   - `issue_project_fixed/data/`
3. Copy all data files from `issue_project/data/` to `issue_project_fixed/data/`
4. Copy `requirements.txt`, `example_usage.py`, and `README.md` to `issue_project_fixed/`

### Phase 3: Implement the Fix
1. **Fix the root cause** in `normalizer.py`:
   - Replace unordered `set` iteration with deterministic ordered iteration using `list()`
   - Use vectorized operations for calculations to ensure consistent floating-point sequences
   - Eliminate any order-dependent logic in threshold decisions

2. **Maintain all business logic:**
   - Z-score normalization algorithm must remain unchanged
   - Correlation calculation methodology must be preserved
   - Weighting strategy must remain the same
   - API and interface must be identical

3. **Create test infrastructure:**
   - Copy and update `tests/test_normalizer.py` with deterministic assertions
   - Add `tests/conftest.py` to configure test imports if needed
   - Ensure tests verify that identical inputs produce identical outputs

### Phase 4: Validation & Testing
1. Install dependencies: `pip install -r requirements.txt`
2. Run single test pass: `pytest -q`
3. Run repeated tests (20 iterations minimum): `pytest -q --count=20`
4. Run example script: `python example_usage.py`
5. Verify that:
   - All tests pass consistently (100% success rate across all runs)
   - Example script produces deterministic output (e.g., score = 7.500000)
   - No errors or tracebacks occur

### Phase 5: Documentation
1. Create `FIX_SUMMARY.md` containing:
   - Detailed explanation of what was changed (specific files/lines)
   - Root cause analysis and why the fix resolves the issue
   - Step-by-step verification instructions
   - Trade-offs or performance considerations (if any)

2. Update `README.md` to:
   - Clearly indicate this is the fixed version
   - Include test results demonstrating consistency
   - Provide updated quick-start instructions

3. Copy `KNOWN_ISSUE.md` as-is to preserve the original issue description
